Vehicle Rental System

1. Problem Statement
Develop a Java-based Vehicle Rental System that allows users to view, rent, and return vehicles. The system supports availability checking, rental charge calculation, vehicle searching, and rental history management.

2. Objectives
•	Display all vehicles and rental prices.
•	Rent and return vehicles.
•	Check vehicle availability.
•	Calculate rental charges based on rental days.
•	Search vehicles by brand or model.
•	Maintain rental history and return status.

3. Technologies Used
•	Programming Language: Java
•	IDE: Eclipse
•	Concepts: Object-Oriented Programming, Classes, Objects, Encapsulation, ArrayList, and Exception Handling.
4. Project Structure
•	"Vehicle" – Stores vehicle details.
•	"Rental" – Stores rental information.
•	"VehicleRentalSystem.java" – Main application class.

5. How to Compile and Run

Using Eclipse IDE

1. Open the project in Eclipse.
2. Run "VehicleRentalSystem.java" as a Java Application.

Using Command Line

javac VehicleRentalSystem.java
java VehicleRentalSystem
6. Expected Outcome
The application allows users to manage vehicle rentals, calculate rental charges, update vehicle availability, and view rental history through a menu-driven Java console interface.
7. Data Storage
The application stores vehicle and rental records in "ArrayList". Data is reset when the application is restarted.
